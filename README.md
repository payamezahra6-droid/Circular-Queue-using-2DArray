# Circular Queue Using 2D Array (Java)

## Description
This project implements a circular queue using a two-dimensional array in Java. It demonstrates how queue operations can be performed using a 2D array while following the FIFO (First In, First Out) principle.

## Features
- Enqueue elements into the circular queue
- Dequeue elements from the circular queue
- Display queue elements
- Use front and rear pointers
- Reuse empty spaces through circular movement
- Handle queue overflow and underflow conditions

## Concepts Used
- Data Structures and Algorithms (DSA)
- Two-Dimensional Arrays
- Circular Queue
- FIFO (First In, First Out)
- Front and Rear pointers
- Modulo operator (`%`)
- Enqueue and Dequeue operations

## Technologies
- Java
- IntelliJ IDEA

## How to Run
1. Clone or download this repository.
2. Open the project in IntelliJ IDEA.
3. Run the `Main.java` file.
4. View the output in the console.

## Learning Objective
The objective of this project is to understand the implementation of a circular queue using a 2D array and learn how circular movement allows the reuse of available spaces.
